# 分镜与视觉设计

## 脚本的工作单位

使用以下字段写 Markdown 表或等价结构；已有脚本可保留形式，补足真正影响绘制的信息：

| 字段 | 内容 |
| --- | --- |
| ID / 播放顺序 | 稳定 ID；顺序可变，拆镜可用后缀 |
| 音乐提示 | 歌词、间奏、节拍、音效或台词；无定稿音频时写段落而非假秒数 |
| 剧情与时间 | 此镜提供的新信息；当下/回忆/想象；承接上一镜的方式 |
| 画面 | 景别、视角、人物占比、姿态、表情、场景、前后景关系 |
| 角色约束 | 造型版本、可见眼睛、发型、关键配件、必要配角 |
| 后期 | 字幕区域、轻微运动、强调字、转场；没有必要就留空 |
| 素材与状态 | 参考、已选图版本、未解决问题、确认范围 |

## 先有音乐结构，再有精确时间

1. 列全前奏、主歌、预副歌、副歌、间奏、桥段、尾奏。角色经历不必覆盖所有生平，选择一条可读的情绪变化。
2. 在每段标出可听见的换句与呼吸点。需要对照原片时先看实际原片，再记录镜头变化；不要把抽帧接触表当作完整动作观察。
3. 分镜粒度由动作和叙事决定。同一句可能需要多个反应镜头，几句也可能共用一张有变化的长镜头。
4. 歌声或配乐变化后重新对齐，而不是沿用旧导唱的毫秒数。临时脚本明确标记“时间暂定”。

## 避免重复和时间倒置

给每镜写一句“观众在这里新知道什么”。只改变背景颜色而信息相同，通常应该合并或改写。区别有意重复的视觉母题与没有进展的重复：第二次出现应改变处境、视角、表情、关系或结果。

把故事事件另排一列：困境建立 → 尝试维持 → 代价显露 → 转折 → 余波。音乐允许的对白位置可能很晚，此时可以：

- 在对白前保持困境，用日常片段或象征画面掩饰疲惫；对白揭露先前隐藏的感受；最终副歌再给出回应。
- 先展示当下的平静，由一件物品触发回忆；回忆后返回同一构图，让观众看出变化。
- 若结局已展示，明确通过构图、色彩、字幕或转场建立回望结构，避免看起来像剧情反复发生。

不要为了吻合某一句字面意象，提前画出之后才该发生的释然、相遇或身份揭露。音乐时间和故事时间可以不同，但观看者需要可辨认的连接。

## 人物、服装和画风

人物占比是项目参数。先用样张确定：是否能看清脸和动作，缩略图是否仍有主体。远景承担环境或孤独感时可以小人物；以表情推动的镜头则需要更近，不统一限定每镜百分比。

服装可按故事时期或日常情境变化，保留能识别角色的轮廓和配色。用户要求严守原服装结构时，不以“画风简单”为由删掉关键元素。服装切换记录在镜头中，避免一段连续动作中无理由换装。

参考原片时记录真正需要保持的特征：线条粗细和抖动、平涂或晕染、色数、阴影层级、背景密度、人物比例、边缘处理、留白和文字关系。目标是复现这些可观察特征，而不是只写“二次元”“手绘风”。

配角的用途可为见证、冲突、照顾或关系转折；幻想伙伴/宠物可承接日常笑点、动作或气氛。它们不必每次同时出现，也不应抢走主角情绪焦点。

## 原片路线的额外约束

- 严格换角：保留原片镜头范围、机位、人物动作、字幕时钟及遮挡；先匹配原始帧率和时间基准。更高清的新源需要重新探测，不能只替换文件名。
- 选择性改编：列明哪些段落沿用原片构图，哪些重新设计；不要在用户只同意改一个镜头时全片换风格。
- 角色抠图适用于可拆分场景。边缘脏色、暗圈、缺失水体覆盖，需要正确 alpha、前景遮罩和色边处理，不能靠贴色块或放大来掩盖。
