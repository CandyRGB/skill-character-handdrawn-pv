# 绘图与审核

## 参考与角色表

先查看实际图片、已有成稿和用户批注；文件名或模型介绍不代替目视检查。明确每张参考的作用：

- 身份与结构：脸、身体比例、眼部、发型连接、服装配件、正侧背面。
- 画风：线条、平涂/笔触、阴影、配色与细节密度。
- 构图：相机、主体大小、姿势、场景布局和留白。

没有必要为每位角色生成完整三视图。复用已有确认稿；仅在将出现的新造型、视角或场景结构无法判断时补参考。建筑、道具或景物参考也应经过与人物相同的风格转译，不能把写实模型质感直接混入平面插画。

角色约束记录“哪一侧、什么结构、在哪些镜头可见”，而不只是列关键词：

- 左右以角色自身解剖左右为准，另注明画面左右；正面常相反，背面常同向，三分之二侧面需要具体核对。
- 异色眼需分开记录左右虹膜与瞳孔。不要为显示标志性眼睛，把它搬到实际被遮住的一侧。
- 长发束记录从哪一层头发或后脑延伸、经过肩的前后、与颈部和衣领的遮挡关系。短发外层与长束要自然衔接，不像从肩膀粘出两条带子。
- 头部转动不等于所有长发同时绕到同一侧。结合身体朝向、重力、动作和水流决定摆幅。

## 提示词结构

按当前工具的图片编辑接口传入参考，并使用清楚的角色分工。例如：

```text
任务：制作镜头 <稳定 ID> 的完整画面 / 编辑已选画面中的指定局部。
参考 A 用于角色结构，参考 B 用于线条和上色，参考 C 用于构图。
画面：<人物大小、机位、动作、表情、背景和文字留白>。
角色约束：<本镜可见的身份特征、服装、头发连接及左右关系>。
接触与遮挡：<手放在哪里、身体在水面哪一侧、物件谁在前>。
风格：<具体可观察的线条、色块、阴影和背景密度>。
局部编辑时保留：<构图、脸、其余姿态、背景等已确认内容>。
不要在图里绘制歌词或说明文字，除非本镜明确需要画内文字。
```

不要机械地对所有画风添加“极致细节、电影体积光、皮肤纹理”等词。不要假定图像工具会准确输出字体；通常把歌词、署名和封面标题留给后期排版。

## 整图与图层的选择

静态场景优先一起处理人物和环境：水应覆盖应被淹没的身体，坐姿应压在椅面，手应落在床沿或床面，脚掌应正确接地。这样比先画站立角色再塞进场景更可靠。

当确实需要独立移动时，明确前景遮罩、人物、后景和透明边界。用于抠图的候选应检查 alpha 与半透明边缘；保留背景残色的图片不是真正可合成的素材。人工图层分离和软件遮罩是有用技术，不等于任意画一张带背景立绘后贴上去。

## 每组画面检查

先逐张看实际输出，再用接触表比较整体一致性。重点检查当前镜头的风险，不在每次小修中重复全套审核：

| 风险 | 具体检查 |
| --- | --- |
| 身份 | 脸型、眼睛的左右及瞳孔、发型轮廓、关键配件是否漂移 |
| 头发 | 根部连续、前后关系、发束数量和重力；转头是否带来不合理位移 |
| 手 | 左右手、拇指所在侧、掌面/手背、指甲可见性、手指数量与抓握关系 |
| 身体 | 肩肘腕和膝踝的方向、脚部弯折、承重和姿势是否合理 |
| 场景 | 接触点、水位、家具和肢体遮挡、光线与比例 |
| 风格 | 是否突然变成 3D、精细厚涂、散发或别的线条体系 |
| 连续性 | 相邻镜头服装、物件、方位和剧情状态是否成立 |

用户批注的坐标属于对应图片。先核对版本与画幅，再定位；Windows 路径多出 `/C:/` 时应恢复合法路径，不能把“读取失败”当作已查看图片。

手画反时明确“掌面朝向镜头，指甲在背面不可见，拇指位于画面某侧”等可验证目标；仅写“修手”容易再次错误。局部修订后把修前修后并排查看，防止修好了手却改坏眼睛或发束。

对同类错误连续两次修订失败时，改变输入方式：加局部结构参考、缩小编辑区域、先确认草图或换更明确视角。不要用更多抽象形容词反复生成同一问题。已有用户授权足够时继续修，不凭空增加确认流程。

记录真实状态和未解决问题；用户确认某张后再产生修改，应成为新候选而不是悄悄替换已确认版。
