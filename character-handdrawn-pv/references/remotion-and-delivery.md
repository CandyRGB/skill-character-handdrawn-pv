# 合成、预览与交付

## 合成结构

先检查项目版本与现有 composition，沿用已可用工程。需要 API 细节时先读本地可用的 Remotion skill 和安装版本文档，再查官方资料；不凭旧示例假定当前导出接口。

- 用同一份镜头列表驱动画面、字幕与审核页；不把同一组秒数分别手写进多个组件。
- 总时钟通常是 composition 帧；镜头动画用镜内帧。提前揭示下一张画面不代表下一句歌词也应提前，明确画面、字幕和音频各自的时间基准。
- 使用 `useCurrentFrame()` 与 `useVideoConfig()`，通过确定性的插值或弹簧表达动画。随机装饰需固定种子；不用与渲染时钟无关的 CSS 动画、定时器或系统时间。
- 分辨率、帧率与总帧数来自当前工程目标，不能把素材刷新率当成输出帧率。秒数转帧统一规则并避免逐段四舍五入累积误差。
- 单层整图只做保持构图的推拉、平移、摇动和适量图形覆盖。关节运动、遮挡变化需要合适的素材或真实图层；平面人像不能靠网格扭曲修复错误姿态。

## 克制但有效的动效

先找到长静止区间以及音乐重拍、情绪词、音效，再选择少量能回应内容的变化：

| 情境 | 可用做法 |
| --- | --- |
| 长句共用一图 | 微推拉、视线引导或遮罩显露局部，不让所有镜头持续漂移 |
| 情绪关键词 | 单字稍放大、错位、变色或停留；保留歌词阅读顺序 |
| 重复歌词 | 在第二次改变排版、少量图形或构图，不机械复制同一动画 |
| 水、风、光等意象 | 与画风一致的线、色块或波纹；避开面部和关键动作 |
| 入水与出水 | 冲击、覆盖、持续水下运动、退去构成一次转场 |

复杂效果先在相关片段中预览。轮廓出现不自然尖角、遮挡误读或不合画风时，修改几何形状、遮罩或密度，不靠添加更多粒子解决。静止也是节奏的一部分，独白和情绪停顿不必铺满动效。

字幕通常由合成层负责；检查字体实际可用、中文显示完整、安全区域和缩略图可读性。标题、歌词、强调字、署名避免同时争夺注意力。配色、线粗和出现方式从插画延伸，不默认高饱和爆炸字或复杂装饰。

## 预览审核

给出已启动且可播放的预览 URL、composition 名称及变更涉及的时间范围。预览需要正确加载音频、全部镜头和字体，不能用截图页替代播放。

检查范围与改动相称：

- 单图替换：检查该镜头及前后衔接、字幕位置。
- 时长/音源变更：重新检查受影响的后续时间、音画同步和结尾。
- 全片初次合成：查看接触表，并播放关键剧情、转场和音频段落；可行时通看全片，无法完成则明确范围。

不要把“浏览器打开”“图像加载”“波形无削波”分别说成“已完整观看”“已听过”“混音没问题”。保存助手检查与用户确认的版本和范围，避免用户审的画面与待导出画面不同。

## 导出与验证

用户已在本轮或之前明确授权目标版本导出时直接执行；只授权预览、授权被撤回或请求修改后先看时不导出。项目状态记录授权证据只是保留上下文，不要求用户再填写表或逐镜批准。

导出前确认所有引用来自当前已选版本，音频无临时测试轨，画幅、帧率、全长与发布目标吻合。导出过程较长时持续简短更新，不启动多个相同渲染浪费资源。

编码完成后探测真实成片，而非仅检查进程返回码：分辨率、帧率、时长/帧数、音轨、像素格式和目标播放器兼容性；可做完整解码检查，并抽看编码后关键帧和试听风险段。声音与图片的最终检查要针对实际成片或明确记录所检查的同源音轨。

记录导出文件、composition、工程版本、音频版本与必要参数；摘要或哈希可用于区分同名旧文件。完成合适检查后交付，不反复扩大测试。

## 封面、简介和署名

先按镜头顺序映射稳定 ID，确认用户所指“第 N 张”是哪张，不直接当成 `SN`。基于已选图设计封面，保护角色脸和叙事区域；默认继承作品的细节密度和情绪。吸引力可来自明确主体、构图、留白和可读标题，而非大量装饰。

标题与简介准确反映作品。核对用户署名、原曲/原唱、填词、演唱、音色模型作者、画面、后期；未知来源标记待补，不推测。说明 AI 参与的实际环节，不把模型合成写成声优亲自演唱。发布平台规格变化时查询当前官方资料。

交付本地封面和可复制简介即可满足“发布素材”的请求。上传、发帖或联系他人需要对应授权，制作素材本身不包含这些操作。
